## v0.1.0 — Tool Expansion

Expanded from 4 to 10 MCP tools for comprehensive CUBRID exploration.

### New tools
- `describe_table` — columns + PK + indexes in one call
- `list_indexes` — per-table index metadata
- `explain_query` — execution plan via SET TRACE / SHOW TRACE
- `table_row_counts` — COUNT(*) sweep with whitelist + quoted idents
- `list_serials` — CUBRID SERIAL sequences
- `list_class_hierarchy` — CUBRID CLASS inheritance

### Internal
- Unit + integration tests for every new tool
- Removed bandit (every finding was a false positive; SQLAlchemy doesn't use it either)

Closes #21
